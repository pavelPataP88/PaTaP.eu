# AI TASK — PaTaP.eu

## Текущий блок: MAP_LAZY_CSS

Работаем только над этим маленьким блоком. Базовая ветка и источник истины: `codex/local-workspace-snapshot`.

### Задача

В Driver Patap библиотека MapLibre JavaScript уже загружается только при открытии карты авторизованного водителя. Но её CSS пока подключается заранее в `driver/index.html`. Из-за этого гостевой режим загружает лишний тяжёлый ресурс карты.

Сделай так, чтобы CSS MapLibre тоже загружался только тогда, когда действительно запускается интерактивная карта авторизованного водителя.

### Что должно получиться

1. Гостевой Driver не содержит заранее подключённый MapLibre CSS и не должен его загружать.
2. Когда авторизованный водитель впервые открывает раздел «Карта», CSS и JavaScript MapLibre загружаются безопасно; карта остаётся нормально оформленной.
3. Повторные переходы к карте не создают второй `<link>` или второй `<script>`.
4. Если CSS или JavaScript карты не загрузились, сайт показывает понятное сообщение, а профиль, контакты и чат продолжают работать.
5. Добавь небольшие автоматические тесты именно на это поведение. Не проверяй только по тексту в коде: тест должен подтверждать отсутствие ранней загрузки и отсутствие повторного подключения.
6. Сохрани текущие URL/версии MapLibre, если для их изменения нет технической причины.
7. Не меняй `main`. Не трогай сервер, Caddy, авторизацию, минимальный пароль (6 символов), SQLite, пользователей, GPS-данные, сообщения, токены, логи и runtime.

### Как передать результат

1. Создай отдельную ветку от актуальной `codex/local-workspace-snapshot`, например `chatgpt/map-lazy-css`.
2. Сделай код и тесты только этого блока.
3. Запусти подходящие тесты в своей среде, но не называй результатом то, что не запускалось.
4. Обнови `AI_HANDOFF.md`: ветка, commit, список файлов, реальные команды/результаты тестов и что намеренно не менялось.
5. После этого жди проверки Codex. Следующий блок не начинай.
