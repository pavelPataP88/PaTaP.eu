# PaTaP.eu

Исходный код сайтов **Patap Lab** и **Driver Patap**.

Рабочие версии сайтов:

- https://patap.eu
- https://driver.patap.eu

## Для инженерного анализа

Полный безопасный снимок исходников находится в папке `engineering-source`. Он содержит код, настройки запуска, тесты и документацию. Архив разделён на части только из-за технического ограничения загрузки на GitHub. Как его собрать — написано в [engineering-source/README.md](engineering-source/README.md).

Перед анализом прочитайте [AI_REVIEW.md](AI_REVIEW.md).

В репозиторий намеренно **не добавлены** пароли, токены, база пользователей, сообщения, координаты, журналы работы и временные файлы. Фоновая картинка сайта также не нужна для инженерного разбора и остаётся на рабочем сервере.
