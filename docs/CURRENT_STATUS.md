# Текущий статус PATAP.EU

Актуально на 19 августа 2026 года. Это краткая точка входа для разработчиков и AI. Полное подтверждение последних изменений находится в `AI_HANDOFF.md`, а рабочий снимок кода — в ветке `codex/local-workspace-snapshot`.

## Публикация

Сайт работает на ноутбуке владельца. GitHub — инженерная копия, а не production-сервер.

```text
Cloudflare Tunnel → Caddy (127.0.0.1:8090) → статическая сборка
                                            → Node API (127.0.0.1:8091) → SQLite
```

Проверка состояния на ноутбуке:

```powershell
.\status-patap-stack.cmd
```

Оба адреса доступны без входа в безопасном гостевом режиме:

- `https://patap.eu` — Patap Lab;
- `https://driver.patap.eu` — Driver Patap.

Гости видят только демонстрационный интерфейс. Им недоступны реальные GPS-координаты, контакты, сообщения, записи рации и администрирование.

## Что работает

### Patap Lab

- регистрация, вход, сессии и сброс пароля через одноразовый токен администратора;
- CSRF-защита, rate limit, роли и журнал аудита;
- минимальный пароль — **6 символов**.

### Driver Patap

- добровольный GPS, карта MapLibre, водители рядом и дорожные события;
- поиск, контакты и блокировки;
- общий, личный и групповой чат: роли, вложения, голосовые сообщения, опросы, ответы, редактирование, удаление и закрепления;
- рация: общий и закрытые каналы, роли, live-эфир и сохранённая история передач.

## Правила дальнейшей работы

- Не менять `main` без отдельного решения владельца.
- Не публиковать SQLite, пользователей, GPS, сообщения, audio uploads, токены, пароли, логи, `data/`, `var/` или `node_modules/`.
- Перед новой задачей читать `AI_TASK.md`, `AI_HANDOFF.md` и [CURRENT_ENGINEERING_STATE.md](CURRENT_ENGINEERING_STATE.md).
- Каждый новый блок делать отдельно: код → тесты на ноутбуке → применение только после PASS.
