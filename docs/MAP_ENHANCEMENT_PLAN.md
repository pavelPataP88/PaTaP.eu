# MAP ENHANCEMENT PLAN — PaTaP Driver

Рабочий чек-лист блока MAP_ENHANCEMENTS_V1. Этот файл нужен, чтобы не потерять подпункты при большой доработке карты.

## Границы
- Только карта/GPS/визуализация уже доступных дорожных событий и ближайших водителей.
- Не менять auth, SQLite schema/data, Caddy, chat, radio, minimum password, main, runtime production data.
- Не добавлять выдуманные парковки/POI без реального источника данных.
- Сохранить lazy MapLibre и guest read-only road reports.

## Подзадачи и статус
1. ✅ GPS camera modes: свободно / следить / по курсу.
2. ✅ GPS accuracy circle + текст качества GPS.
3. ✅ Автоматическое отпускание follow mode после ручного drag/rotate карты.
4. ✅ Улучшенные маркеры водителей по типу TIR/TAXI/DELIVERY/GENERAL.
5. ✅ Свежесть дорожных событий: визуальное затухание по TTL.
6. ✅ Панель «Впереди»: до 3 ближайших дорожных событий относительно позиции/курса.
7. ✅ Слои карты: дорожные события / водители / круг поиска; состояние хранится локально.
8. ✅ «Что рядом»: краткие счётчики по текущим данным без раскрытия приватных данных.
9. ✅ Масштаб-зависимая плотность: кластеры road reports и drivers на дальнем zoom, компактные labels на мобильном.
10. ✅ Радиус поиска: серверные 5/25/50/100 км сохранены; добавлены понятные подписи и opt-in авторадиус по zoom.
11. ✅ Road Report offline queue: максимум 2 минуты; повторная отправка только при свежем GPS и если водитель остался рядом с исходной точкой.
12. ✅ Доступность: aria-label/status, touch targets >= 44px, обычные button/checkbox controls.
13. ✅ Mobile/tablet layout: GPS switch/radius/status перенесены в overlay «Слои»; карта получает больше высоты.
14. ✅ Guest map: код не менялся; остаётся read-only и lazy.
15. ✅ Regression tests: follow/accuracy/layers/ahead/TTL/clusters/offline/lazy/guest + актуализация старого road-report test.

## Сознательно не имитируется без реального источника/отдельного решения
- Парковки, TIR parking, fuel, AdBlue, сервисы: в UI есть пояснение, но фейковые POI не создаются. Нужен отдельный проверенный источник данных и юридические условия.
- Полноценная offline-карта/скачивание тайлов: не реализуется поверх публичных OSM tiles без отдельной tile/offline policy. Текущая карта сохраняет обычное поведение browser cache, но это не заявляется как offline maps.
- Голосовые/звуковые предупреждения: не включаются автоматически. Для водительского продукта нужен отдельный opt-in UX и тест на отвлечение; дорожный контроль/инспекция не должны превращаться в систему уклонения.
- Полноценная пошаговая навигация/route engine и live traffic engine.
- 3D terrain/buildings.
- Speed trap, обход контроля, маршруты уклонения.
