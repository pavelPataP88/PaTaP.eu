# MAP ENHANCEMENT PLAN — PaTaP Driver

Рабочий чек-лист блока MAP_ENHANCEMENTS_V1. Этот файл нужен, чтобы не потерять подпункты при большой доработке карты.

## Границы
- Только карта/GPS/визуализация уже доступных дорожных событий и ближайших водителей.
- Не менять auth, SQLite schema/data, Caddy, chat, radio, minimum password, main, runtime production data.
- Не добавлять выдуманные парковки/POI без реального источника данных.
- Сохранить lazy MapLibre и guest read-only road reports.

## Подзадачи
1. GPS camera modes: свободно / следить / по курсу.
2. GPS accuracy circle + текст качества GPS.
3. Автоматическое отпускание follow mode после ручного drag карты.
4. Улучшенные маркеры водителей по типу TIR/TAXI/DELIVERY/GENERAL.
5. Свежесть дорожных событий: визуальное затухание по TTL.
6. Панель «Впереди»: до 3 ближайших дорожных событий относительно позиции/курса.
7. Слои карты: дорожные события / водители / круг поиска; состояние хранить локально.
8. «Что рядом»: краткие счётчики по текущим данным без раскрытия приватных данных.
9. Масштаб-зависимая плотность: скрывать подписи/детали на дальнем zoom и не перегружать карту.
10. Радиус поиска: сохранить серверные 5/25/50/100 км, но добавить понятные подписи и автоматический выбор по zoom только по явному действию пользователя.
11. Road Report offline queue: очередь только для краткого сетевого сбоя, с TTL очереди и повторной проверкой свежего GPS перед отправкой; не отправлять устаревшие события.
12. Доступность: aria-label/status, touch targets >= 44px, управление с клавиатуры.
13. Mobile/tablet layout: controls поверх карты, без отдельной высокой панели.
14. Guest map: только read-only, без create/confirm/GPS.
15. Regression tests: follow/accuracy/layers/ahead/nearby/TTL/offline/lazy/guest.

## Не входит в этот блок
- Полноценная пошаговая навигация/route engine.
- Live traffic engine.
- 3D terrain/buildings.
- Реальные parking/fuel/service POI без отдельного проверенного источника данных.
- Speed trap, обход контроля, маршруты уклонения.
