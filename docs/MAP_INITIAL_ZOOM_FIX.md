# MAP_INITIAL_ZOOM_FIX

Статус: применено после локальной проверки.

## Поведение карты

- Авторизованная карта стартует не дальше масштаба 11.
- Первый свежий GPS один раз центрирует карту на водителе с масштабом не меньше 14.
- Последующие GPS-обновления не меняют масштаб.
- Если водитель приблизил карту сильнее 14, масштаб не уменьшается.
- После выключения GPS следующий запуск получает один новый автофокус.
- Кнопка `⌖` возвращает к водителю, включает слежение и приближает до масштаба не меньше 14.

Исправление не меняет сервер, базу, вход, чат, рацию или runtime-данные.
